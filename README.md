# BTÜ Bilişim ve Kodlama Topluluğu Veri Yapıları eğitim materyalleri

Eğitim materyalleri dosya içerisinde l0'dan başlayarak sıralanmıştır.
Her eğitim için gerekli materyaller eğitim öncesinde bu github sayfasında paylaşılacaktır

Linux kullandığım için eğitim içerisinde kullanılacak programlar .out formatında linuxa uygun derleniyor, eğer kendiniz bu programları windows bir cihazda çalıştırmak isterseniz yeniden derlemeniz gerekecektir.
